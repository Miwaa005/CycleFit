# CycleFit

## 1. Initial concept
CycleFit is a cycle and wellness app that combines menstrual cycle tracking, exercise suggestions, and mindfulness tools. The purpose is to help women through different symptomps of each menstrual phase by giving insight in current phase, as well as encourage suited exercise and meditation throughout the cycle.

## 2. How AI was used
AI was used to brainstorm the app concept, design test cases, generate the initial HTML/CSS/JavaScript prototype, suggest improvements to the user experience and recommendation logic.
